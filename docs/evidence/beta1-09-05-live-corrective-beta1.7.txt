Defect and correction
---------------------

The first Beta.1.6 live smoke returned HTTP 404 for exact `GET /register`.
The dynamic registration leaf handler existed and its mode tests passed, but
the authenticated-router constructor never assigned that handler to the
exact-path dispatch boundary. The correction passes the dynamic handler
through the already-admitted optional-session wrapper and assigns it to the
dispatcher. It changes no schema, data, role, permission, secret, Authentik
object, Caddy route, or registration mode.

The full-router regression is a negative/positive control:

- on Beta.1.6 it fails with `status 404`;
- on the corrective tree it returns HTTP 200 with request pattern
  `GET /register` and the closed-registration presentation;
- 50 focused race-detector repetitions pass.
