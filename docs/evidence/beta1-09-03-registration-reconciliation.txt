Results
-------

- Public admission is a no-store, mode-exact, SMTP-gated read. Approval intake
  accepts only a bounded, flow-bound, short-lived provider-signed assertion and
  returns the fixed non-oracular response grammar before idempotent local
  persistence.
- OIDC session creation denies every non-approved pending identity. Pending
  administration is bounded, exposes no immutable Authentik coordinates, and
  adopts an orphan only after a signed-handle re-fetch proves exact numeric ID,
  UUID, verified profile, active state, pending membership, and absence from
  accepted and suspended groups.
- Approval and rejection commit restrictive local intent before gateway work,
  perform no remote I/O under a PostgreSQL transaction, verify exact final
  accepted/pending/suspended membership, and commit terminal state only for the
  same request and revision. Failure remains restrictive and retryable.
- Invitation creation reserves a redacted HMAC fingerprint before remote work,
  adopts only an exact remote name/flow/profile/expiry match, never resends mail
  after ambiguity, and stores neither recipient nor invitation UUID/link.
  Browser retries preserve one absolute expiry reference. The list is loaded
  before mutation, so no post-commit remote read can suppress a newly created
  one-time link. Revocation distinguishes confirmed deletion from an already
  absent single-use token and from an ambiguous result.
- Local suspension and all-session revocation commit before Authentik removal.
  Reinstatement and finite expiry grant and verify Authentik first, while the
  local `accepted` sync-state predicate continues denying access, and clear the
  suspension only in the guarded completion transaction.
- Explicit administrator reconciliation retries one restrictive identity.
  The startup/60-second worker claims at most five finite expiries under a
  transaction-scoped advisory lock, holds no database lock across gateway I/O,
  retries failures no sooner than one minute, and records concurrent local
  changes as superseding rather than overwriting them.
- Every protected session, publication, report, moderation, site, and
  administration authorization path now requires persisted Authentik sync
  state `accepted`. PostgreSQL race tests prove stale `removal_required` and
  `grant_required` staff cannot mutate or append an audit.
- SMTP connection, implicit-TLS handshake, protocol, and DATA acceptance share
  one total configured deadline. A silent implicit-TLS peer is proven to time
  out. The standalone closed configuration carries all six exact empty SMTP
  values; preflight rejects missing values or premature standalone enablement.

Rejected intermediate work
--------------------------

- Authorization originally trusted a session actor after its persisted sync
  state became restrictive. The final queries and transactional actor locks
  require `accepted`; failure tests prove no mutation or audit occurs.
- Early gateway membership mutations trusted an action acknowledgement. The
  final gateway performs a filtered readback, and Board independently verifies
  the complete three-group state before committing success.
- Invitation form retries originally recomputed expiry from the retry time,
  changing the request fingerprint. The final hidden canonical reference keeps
  an identical submitted request identical.
- Invitation POST originally listed remote state after successful creation.
  That could hide the only returned bearer link if the follow-up read failed.
  The final handler loads the bounded presentation before mutation.
- Implicit SMTP TLS originally bounded TCP dial but not the TLS handshake. A
  silent peer could hang the request. The final total deadline is installed on
  the socket before the handshake and has a stalled-peer regression test.
- The first standalone candidate required SMTP variables in application code
  but omitted the disabled sentinel from its packaged environment. The final
  example and preflight make a closed deployment startable while keeping shared
  standalone SMTP wiring explicitly in B1-09-04.
