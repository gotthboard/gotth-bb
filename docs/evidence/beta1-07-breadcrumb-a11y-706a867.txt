Defect and correction
---------------------

The live Beta.1.1 accessibility gate found Axe rule `link-in-text-block` with
serious impact on the populated Activity breadcrumb. Its Board index link was
distinguished from adjacent breadcrumb text only by color. This violates the
admitted Beta accessibility matrix; it is not recorded as an acceptable Axe
incomplete.

The correction makes breadcrumb links persistently underlined. It does not
change their targets, HTMX behavior, authorization, data, or navigation
semantics. The generated Tailwind stylesheet therefore receives a new full
SHA-256 content address. Both previously published stylesheet byte streams are
still embedded, registered for GET and HEAD, exempt from request admission,
and served with the existing one-year immutable cache contract. New HTML emits
only the current stylesheet.
