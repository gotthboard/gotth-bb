Results
-------

- Every exact-tree gate passed. Repository-wide race coverage passed for all
  packages. `internal/abuse` statement coverage was 94.2% in the focused gate
  and 93.1% in the repository-wide race gate; `internal/config` was 99.7%.
- Configuration proves all eight required AN-05 values, canonical counts,
  bounded Go durations, the new/established relationship, and an absolute,
  clean, non-root, NUL-free rules path of at most 4,096 bytes.
- The loader proves descriptor custody across pathname replacement, regular
  non-writable file enforcement, 65,536-byte and 256-rule bounds, empty and
  maximum policies, strict ordering/uniqueness, encoding/line controls, DNS,
  IDNA, IP, URL, port, escape, query, fragment, and dot-segment rules. Errors
  contain no path, rule, URL, or configured value.
- Request tests cover IPv4, IPv6, mapped IPv4, malformed peers, production
  loopback custody, direct non-production identity, duplicate/comma/space/
  port/zone/noncanonical forwarding, alternative identity headers, exact
  health/static exemptions, near misses, unknown charged routes, body
  non-consumption, 429/503 shape, capacity reclamation, restart reset, clock
  regression, HMAC collision sharing, and exact concurrent admission.
- Request state never exceeds configured capacity and retains only HMAC-SHA-256
  digests, window starts, and counts. No goroutine, timer, raw address, account
  lookup, body read, session lookup, router match, or database operation is
  introduced by admission.
- Observer tests prove fixed class/route/status/retry/request-ID fields, input-
  free logs, invalid-event suppression, and that a slog handler error cannot
  change the already selected response.
