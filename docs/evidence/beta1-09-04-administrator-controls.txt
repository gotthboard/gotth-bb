Results
-------

- `GET|POST /admin/control` exposes the closed runtime-control fields through
  one revision-guarded, ceiling-bounded, audited transaction. Registration
  cannot leave `closed` without valid shared SMTP configuration.
- Session pages select at most 51 effectively active local sessions at one
  database time, render 50 plus an overflow sentinel, and expose only finite
  issued, last-seen, last-validated, and expiry times.
- Single-session actions use a five-minute HMAC handle derived under a
  distinct domain from the exact current administrator session credential.
  The handle binds actor, target user, target session, action domain, and
  expiry and cannot authenticate a browser session.
- Single and all-session revocation revalidate actor and target, apply the
  configured idle cutoff in the mutation itself, and commit the mutation and
  count audit atomically. Revoking the request's current session clears the
  scoped browser cookie only after commit.
- The email page exposes only `configured` or `disabled` plus the requesting
  administrator's own bounded state. A test has no recipient field, snapshots
  the current verified local address, reserves one server-generated UUID per
  five minutes before SMTP, and commits one separate redacted terminal result.
- Invitation and test mail share one concrete SMTP transport. Connection,
  TLS, protocol, DATA write, and final acceptance remain under the configured
  total timeout. The test message is fixed and contains no link, credential,
  account data, or user text.
- Standalone preflight requires one root-owned mode-0440 SMTP password file,
  an exact matching Board/Authentik tuple, canonical port and whole-second
  timeout, closed TLS-mode mapping, and password/authentication consistency.
  Board and both Authentik processes receive the shared mount; the isolated
  control gateway receives neither the tuple nor the password. Disabled and
  unauthenticated states require the password file to be exactly empty, and
  production plaintext is rejected before Compose starts.
- The complete administrator navigation and exact control/session/email route
  metadata are present. Full-page and HTMX behavior share CSRF, revalidation,
  body, method, base-path, focus, cache, and error boundaries.
- Tailwind output moved to its actual content-addressed name. The immediately
  preceding immutable URL remains served with its exact original bytes.

Rejected intermediate work
--------------------------

- Evidence commit `44720cc` claimed B1-09-04 admission while the standalone
  preflight still rejected all enabled SMTP and Authentik received no shared
  transport. That evidence was false and is superseded by this record. The
  clean-review count was reset before the standalone repair.
- The first standalone repair used Compose `:-` defaults. Empty host values
  therefore rendered as Authentik `localhost` defaults after preflight had
  compared them as empty, creating hidden disabled-state drift. The reviewed
  candidate uses `${VAR-}` literal empty propagation, and disposable Compose
  plus pinned-Authentik runtime checks prove both states.

- The first revocation SQL treated every unrevoked, unexpired row as active.
  That could revoke and count an idle-expired session absent from the page.
  The final SQL applies the same issued, last-seen, validated, expiry, and
  configured-idle predicates inside each atomic mutation.
- The first generated stylesheet update changed bytes under the existing
  immutable filename. The final candidate rotates to the actual SHA-256 name
  and pins generation to that digest.
- The first rotation removed the immediately preceding immutable stylesheet
  URL. The final handler retains and verifies it as a separate route; internal
  cleanup is not allowed to break cached userspace.
