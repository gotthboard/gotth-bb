B1-09-06 administrator SMTP / Beta.1.8 live candidate evidence
Date: 2026-09-13

Scope
-----

Beta.1.7 correctly kept registration closed when SMTP was absent, but exposed
non-closed registration choices without an administrator-owned way to satisfy
that prerequisite and returned only a generic 422. This repair moves SMTP
configuration into /admin/email, preserves a write-only password boundary,
applies the exact saved revision to Authentik through the isolated gateway,
and requires a successful self-addressed test of that revision before any
non-closed registration mode is available.
