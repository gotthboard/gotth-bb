Results
-------

- Every final exact-tree gate passed. Repository-wide unit race/coverage and
  the complete PostgreSQL serial/race package set passed.
- Unit statement coverage on the changed core packages was 92.6% for
  `internal/abuse`, 95.9% for `internal/render`, 88.6% for `internal/forum`,
  and 72.5% for the broad HTTP package. PostgreSQL integration coverage was
  93.7% for `internal/forum`, 97.1% for `internal/store`, and 100% for
  migrations and readiness.
- The policy matcher covers empty, one-entry, and 256-entry domain and exact
  URL sets. It proves IDNA, exact/subdomain/sibling matching, one trailing DNS
  root dot, discarded userinfo, IPv4/IPv6, default/nondefault and normalized
  ports, empty/dot/escaped paths, percent case and unreserved decoding,
  reserved bytes, query order/encoding, ignored fragments, and exact URL
  distinction.
- Browser-ambiguous protocol-relative and slash/backslash forms plus malformed
  HTTP(S)-looking destinations fail with the same content-free typed error.
  Relative references, anchors, mailto, code spans, fences, escaped text, and
  inert raw HTML remain under the existing renderer/sanitizer policy.
- Inline, reference, collapsed-reference, image, and GFM URL-autolink cases are
  checked by walking the one Goldmark AST that is subsequently rendered.
  Repeated destinations and the exact 65,536-byte source boundary pass. The
  mechanism contains no resolver, HTTP client, network call, retry, cache, or
  background work.
- Topic/reply/edit preview and mutation plus nonempty community-rules settings
  all receive one explicit validated destination policy. Topic/reply/edit
  mutation rejects before transaction begin; settings rejects before its
  audited transaction. Preview/edit/settings do not touch publication state.
  Existing stored post and rules reads continue through the ordinary renderer
  and are not rescanned or rewritten.
- Full-page and HTMX blocked responses are fixed 422 with `private, no-store`;
  topic/reply rate responses are fixed 429 with positive integer
  `Retry-After`, `private, no-store`, and the escaped submitted draft. Topic,
  reply, edit, and settings tests prove the one fixed observer event and exact
  route class. Member, moderator, and administrator publication attempts all
  receive the same blocked result before transaction begin.
- A combined real access-log and abuse-observer test supplies unique client
  address/header, account/session, raw-query, Markdown, destination/rule,
  configured-count, map-occupancy, cookie, and secret sentinels. It proves one
  fixed rejection event, bounded completion records, and zero sentinel bytes
  in the logs.
- JavaScript-disabled Chromium through Caddy preserves blocked topic, rate
  topic, blocked edit, and blocked community-rules submissions, including the
  current settings revision, and observes exactly four fixed terminal events.

Rejected candidates and repairs
-------------------------------

- The first AN-05-03 implementation lacked browser-through-Caddy evidence.
  The candidate added a real JavaScript-disabled Chromium gate for blocked and
  rate-limited forms before admission.
- The initial exact rerun exposed an expired AN-04 integration fixture: it
  inserted accounts at database wall time but compared them with a fixed
  September 8 15:00 UTC observation. Once wall time passed that instant, its
  mute violated `users_muted_after_creation`. The repair pins fixture creation
  one hour before the fixed observation; production code is unchanged and the
  case passed three consecutive PostgreSQL runs.
- Chromium's main process could exit while a profile subprocess still created
  files, making recursive cleanup intermittently fail with `ENOTEMPTY`. The
  test now uses Node's bounded `fs.rm` retries and passed five consecutive
  browser-through-Caddy runs.
- Cold pass 1 on `ac39ccc` rejected missing executable log-sentinel search and
  role-bypass evidence. `9ed8a13` adds the smallest two tests. Review note:
  `/tmp/gotth-bb-an05-03-judge-1.md`.

Non-gate invocation mistakes
----------------------------

- A focused remote `go test -run` attempt passed an unquoted shell expression
  containing parentheses and `|`; the remote shell rejected it before Go ran.
  It was not treated as a gate. Three literal-pattern invocations replaced it
  and each passed 50 times.
- One early serial PostgreSQL sweep failed only at the expired AN-04 fixture
  described above. No passing claim was made until the deterministic fixture
  repair and complete exact-tree reruns passed.
