Candidate changes
-----------------

- Added an exact bidirectional comparison between all 68 PRD requirement IDs
  and all 68 traceability rows. Duplicate, omitted, invented, empty, malformed,
  non-regular, oversized, NUL-containing, or unterminated inputs fail.
- Added syntax-tree extraction of production GET/POST routes, explicit
  accounting for manual OIDC/setup dispatch and four GET/HEAD static assets,
  rejection of unknown router operations, emitted URL-shape checks, and exact
  comparison with the 61-row reviewed route table (65 method/path pairs).
- Every route metadata field is nonempty; every POST row records CSRF `yes` and
  every GET/HEAD row records `no`.
- Upgraded `golang.org/x/net` to 0.56.0 and `golang.org/x/text` to 0.39.0,
  including their required module graph. This closes reachable GO-2026-5970
  and GO-2026-5026 and imports fixed HTML parser handling for GO-2026-5025
  through GO-2026-5030 and GO-2026-5942/4918.
- The newer parser deliberately deduplicates malformed attributes. The
  persisted-content boundary therefore compares raw task-list input tags with
  three exact renderer-admitted spellings before tokenizer normalization.
  Duplicate, boolean, self-closing, uppercase, extra-space, truncated, and
  extra-attribute spellings are rejected.
- The Caddy browser gate now requires all eight fixed application browser
  security headers to survive the proxy at both empty and `/bb` base paths.
- The existing deployed 30-minute revalidation value has an explicit config
  acceptance test. Database-current role, group, suspension, mute, session
  revocation, and stale revalidation paths remain covered by the exact unit and
  PostgreSQL integration suites.

Results and coverage
--------------------

- Every exact gate above passed on commit `f91a6fb` / tree `1759e43`.
- Serial/race integration coverage included 97.2% `internal/auth`, 93.7%
  `internal/forum`, 83.6% `internal/moderation`, 97.1% `internal/store`, and
  100% migrations and readiness. HTTP unit race coverage was 72.5%; its
  branch-heavy unavailable/denied/full-page/HTMX behavior is supplemented by
  the named focused and browser tests rather than hidden by an aggregate.
- Caddy structurally adapted the canonical request-header overwrite and live
  requests saw one `127.0.0.1` X-Forwarded-For value with Forwarded and
  X-Real-IP deleted. Fixed CSP, frame, MIME, referrer, opener/resource,
  permissions, and origin-agent headers survived the proxy.
- No schema or production data was changed. The task PostgreSQL container,
  package, image, scan container, reports, and remote exact checkout remain
  task-owned scratch until the wider Beta gate no longer needs them.

Rejected attempts and repairs
-----------------------------

- The first vulnerability scan failed on two reachable advisories; the gate
  did not proceed until fixed versions passed.
- The dependency update changed HTML duplicate-attribute behavior and broke a
  sanitizer regression test. Accepting normalized malformed input was rejected;
  the boundary was narrowed to raw exact renderer spellings.
- The first exact custody run found that the checked launcher still encoded
  the old dependency graph. It was reproducibly rebuilt and the final custody
  run passed byte-for-byte.
- `go mod tidy -diff` then found stale sums and misclassified direct `x/sys`.
  The graph was normalized and every exact gate restarted on `f91a6fb`.
- The first image-tar scan warned that Docker's root-owned output was unreadable
  while returning success. That result was rejected; the exact task-owned file
  was made owner-readable and rescanned successfully.
- Binary-string scanning reported six identical public Go module checksums as
  generic keys. They were not waved away: exact rule/count/match and committed
  `go.sum` equality were proved privately, then all remaining strings scanned
  clean.

Remaining boundary
------------------

- B1-01 proves the local and configured 30-minute Authentik revalidation
  mechanism. Disabling an isolated designated identity in the live provider
  and proving failure at the next protected request at/after that interval is
  intentionally deferred to B1-05, where provider administration and deployed
  state are in scope. No immediate-disable claim is made.
- B1-02 still owns the complete Beta accessibility/reflow/zoom and
  representative-plan matrix. B1-03 owns Alpha.2 upgrade/restore rehearsal.
- This is a pre-release candidate package/image only. It is not the final
  reproducibility artifact, tag, merged release, deployment, or known-good
  record.
